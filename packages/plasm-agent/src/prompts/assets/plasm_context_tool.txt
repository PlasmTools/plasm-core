**Returns a language card** with a session symbol table, selected business capabilities, declared prerequisites and input bindings. Call before `plasm` / `plasm_run`; this tool performs no acquisition or business calls.

**Required semantic input:**
- `intent`: the original task on `new`, and the current need on `extend`; the runtime preserves the original. It does not select the session.
- `effect_slots`: every affirmative effect and explicitly requested information outcome, one complete statement per slot. Preserve branch, order, constraints and prohibitions.

Use `session_mode: "new"` once per workflow. Later needs use `session_mode: "extend"`, the same `logical_session_ref`, current `intent`, and current `effect_slots`; existing symbols remain unchanged.

Jev classifies retrieved capabilities against current and unresolved slots. Matched capabilities receive typed input-source projection, prerequisite closure and teaching independently of unresolved slots. The response reports unresolved work and retrieved candidates rejected or judged uncertain. Continue using available teaching within the intent constraints; extend only for missing capabilities. Earlier slots, matches and symbols persist. Capability coverage is not task completion.

Discovery does not choose records, authorize substitute work, acquire data, or execute effects. Ask when needed, then write taught provider and business calls as ordinary Plasm, submit to `plasm`, and execute reviewed `run_ref` plans with `plasm_run`.
