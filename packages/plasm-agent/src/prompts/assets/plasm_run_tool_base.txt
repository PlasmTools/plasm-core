**Run Plasm** (live write / review commit): **`logical_session_ref`** + **`run_ref`** — a `pcN` from **`plasm`** when the plan needed review, or the page handle from a prior "more pages" line. Real HTTP/API; may return **`resource_link`** snapshots.

**When to call:** only after **`plasm`** returned a **`run_ref`** for a mutating / review-gated plan, or to continue paging. Clean read-only **`plasm`** calls already return rows — do not re-run them with **`plasm_run`**.

**Review gate:** first live write executes the reviewed plan for that `pcN`. If the token is missing, expired, or from another plan, call **`plasm`** again.

**Paging:** when a result says `more pages — call plasm_run with run_ref: "…"`, copy that handle into **`run_ref`** (same **`logical_session_ref`**). Use paging only when **no** snapshot was stored. `page(...)` is HTTP-execute program syntax only.

**Live results:** `## {return_label} ({n} rows)` header. Small results (≤25 rows): inline ` ```tsv ` when `result_delivery` is `inline`; `snapshot_only` / `(in artifact)` need the artifact read path (suffix below).

**Retry:** transient `session materialization changed during concurrent execute` — re-issue the same `plasm_run` once.
