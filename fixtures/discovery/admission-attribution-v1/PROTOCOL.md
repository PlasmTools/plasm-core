# Native attribution, without a selection intervention

Collect test-only lexical score/term/field mass and accepted direct-root/optional-path packet construction steps across all 98 existing variants. No fixture, label, budget, production ranking or allocation changes. Native policy remains unchanged. No providers, execution or AppWorld run.

Explain only the first search in each variant, to bound data volume. Every explained ranking must match the normal ranking exactly. The diagnostic plan must emit the same packet as the selected request. Run all active matcher checks and all four cohorts with their original reverse-insertion checks. Compare all historical per-turn fields (including packets, receipts, statuses and outcomes) and operational summaries, excluding only timing; new diagnostic fields do not count as differences. Report any comparison gaps explicitly. Abort on harness or parity faults.

The normalized field masses are pre-saturation inputs to the nonlinear lexical formula; they are not independent additive final-score effects. Term contributions do sum to score. Admission marginal bytes are exact differences in full packed bodies; first admission includes framing. Timings with extra diagnostic construction are not performance measurements.

This is an exploratory stage attribution, not a new candidate or a revised acceptance screen. No tuning or follow-on arm in this run. Preserve all prior evidence and unrelated work.
