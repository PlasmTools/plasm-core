# Native starvation extension v2

Frozen development benchmark, not a blind holdout. V1 remains unchanged.
One baseline only; no ranking or allocation changes in this work.

24 cases: three topologies × neutral/near-topic distractors × 0/100/1,000/10,000
distractors. The zero-size profile pair is a duplicate control, not independent
evidence. Two insertion permutations and four searches per case. Same original
request each search, accumulated exposure and judgment counts. Report horizons
1/2/4. These templates are structural controls, not broad-domain generalization.

Local topology has two valid source suppliers. Spectrum coverage requires ANY
complete listed alternative, not both. Both suppliers are labelled useful, but
one missing supplier is not a failed outcome if another complete path is present.
Telemetry is a separate outcome and must be reported separately.

Cross-catalogue topologies split materials from engine. An explicit deployment
binding chooses the primary or secondary provider for engine.prepare's declared
material_feed requirement. Never infer that edge from equal type names. Noise
owns a same-named Source/string value with unrelated semantics. No noise edge
may enter the useful path. Required acquisition is not optional model nomination.

Neutral and near-topic noise have the same output/effect and identity format;
only authored operation description differs. All noise is unrelated, because it
archives history and cannot produce a spectrum or observe current telemetry.
Near-topic descriptions mention requested actions as conditions/context four
times; this is a deterministic stressor, not an inferred useful capability.

Gold labels enter only the provider callback, after admission. No real provider
or execution backend. Full contracts and question-local references remain intact.
One logical request / 16,000 UTF-8 bytes per search. Existing production transient
retry policy is unchanged; this fixture lane dispatches at most once. No token
budget substitution or extra model work. Provider usage/cost unavailable.

Per-case local execution deadline: 180 seconds after the compiled native test
binary starts, excluding compilation. A timeout is a local construction timeout,
not a ranking loss, model rejection or model-budget event. Preserve incremental
phase checkpoints and completed searches. Never shrink a timed-out case or raise
its bound after seeing results. Run serially; record timings, not causal speedups.

Record actual lexical/frontier rank, required/optional edges, native allocation
receipt, direct-target packet bytes, admitted questions and outcomes. First
blocking stage: unauthorized/index error; no lexical or graph nomination;
allocation budget/cycle/unvisited; judgment rejection; retained. Late rank and
budget deferral can coexist: report both, do not pretend attribution is exclusive
causal proof. Direct packets fitting individually demonstrate crowding, not that
the whole path fits. Record actual selected-path witnesses in the packet.

Integrity gates: source contracts preserved for each target; authorized edges and
declarations only; full required closure; monotonic retention; unchanged budget;
permutation-equivalent receipts; no effects or HTTP calls. Quality failures are
data. Freeze cases, labels, schemas, generator, noise profile and protocol before
native scoring. Pin source and fixture-builder hashes per run. No fixture tuning.

Future candidate adoption: no integrity violations or extra model work; no
outcome-level regressions, improved complete-path coverage by search 4, no new
unrelated admissions. Report both supplier recall and any-path outcome coverage.
Do not average neutral and near-topic stress or exclude timed-out large cases.
