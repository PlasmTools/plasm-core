# Native fixed discovery regression suite v1

Frozen development controls, not a blind holdout. Forty-eight cases: eight
structural families across six vocabulary domains. These are not 48 independent
workflow designs. All labels, requests and source contracts are frozen before
native scores. No ranking candidate is introduced in this work.

Native boundary: CGS loader -> authorized CatalogueSearch -> lexical ranking ->
connected allocation -> complete rendered request -> fixture response through
the real decoder -> retained candidates and required prerequisite closure.
No HTTP provider or execution backend is constructed.

Run each case for four searches, preserving exposed references and visit counts.
Report search 1/2/4, not an unbounded search-until-success. Reversed catalogue
insertion order must produce identical native receipts. Baseline uses fixture
labels only at the provider callback, after packet admission. It cannot use gold
paths or labels for ranking/allocation. Uncertain is retained, not unrelated.
Denials precede index construction. Conditions and original constraints remain
in full evidence. Opaque side effects must retain their original contract.

Failure attribution: unauthorized; not indexed; not ranked/nominated;
allocation deferred (with actual native reason); judged unrelated; retained.
Rank and frontier position are separately recorded for each target. A budget
deferral with a late rank is not silently called model rejection. Expected paths
are sets of necessary members for each outcome; each listed path is independently
reported (including the explicit conditional branch). No execution success claim.

Sensitivity controls inject all-unrelated and all-uncertain answers on one fixed
composition case. They must report judgment rejection and uncertainty retention,
respectively. This validates the reporter, not model accuracy. Existing native
ownership/retry/closure tests remain separate boundary gates; this suite does not
claim to exercise PostgreSQL concurrency or actual transport retries.

Budgets unchanged: one logical request per search, 16,000 UTF-8 bytes;
production transient retries remain <=3 identical attempts/30 seconds/48,000
admitted bytes. This no-fault fixture lane must dispatch <=1 time. Provider usage,
cost and model accuracy are unavailable. No fabricated token usage is returned.

Hard gates: exact source contract fidelity, authorization, complete required
closure, budget bounds, monotonic exposure, stable permutations, and reporter
sensitivity. Quality scores are recorded even when poor; a low recall baseline
does not fail the harness or invite fixture edits. Future candidate adoption needs
zero path regressions, higher complete-path coverage, no extra model work and no
new integrity violations. No tuning or extra arms in this version.

The fixture generator is retained as authoring provenance. cases.json is the
authority and cannot be silently regenerated. Lock source fixture YAML, mappings,
cases, generator and this protocol before baseline scoring. Harness repairs may
change runner code, not locked cases/labels; preserve failed runs and document
repairs. Separately fingerprint native discovery source for each run.

Growth/performance lanes at 100/1,000/10,000 distractors and independently authored
sealed acceptance cases are not represented by this 48-case base suite. They must
be separately versioned rather than implied by vocabulary permutations.
