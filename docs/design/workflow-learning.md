# Workflow teaching library

The OSS-owned library retains complete, evidence-backed programs as optional
teaching examples and associates intents with catalogue capabilities. Agents
author their own programs and continue to use normal plan/review/run. The
library does not serve program fragments or confer execution authority.

Training is session opt-in. An authorized review seals immutable evidence;
successful execution and agent-attested goal satisfaction remain distinct.
Publication and serving remain scoped to the authenticated tenant/project.
Workers do not execute live provider effects to validate examples.

The proposed cutover for applicability, catalogue admission, search progress,
compact semantic contracts and grade-gated settlement is documented in
[Teaching-library recall and discovery](workflow-discovery-redesign.md). Its
proposed behavior is not a statement that every piece is implemented.

Optional fetch stages the current session's dependency exposure, rebinds its
symbols and checks the complete source through normal compilation before the
staged exposure is committed. Unavailable access is request eligibility;
incompatibility is retained for repair. A fetched example is teaching, not
authorization to execute effects.

The older evidence, portability and serving design notes in this directory
contain useful historical analysis, but their fragment extraction and
parameterized direct-reuse descriptions are superseded by the whole-program
teaching model. Use the new design and current Rust implementation for the
active contracts.
