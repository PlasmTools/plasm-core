**Run Plasm** (live): **`logical_session_ref`** + **`run_ref`** — a `pcN` plan commit from **`plasm`**, or the page handle from a prior result's "more pages" line. Real HTTP/API; may return **`resource_link`** snapshots.

**Review gate:** first live run executes the reviewed plan for the `pcN` **`run_ref`** from **`plasm`**. If the token is missing, expired, or from another plan, call **`plasm`** again.

**Paging:** when a result says `more pages — call plasm_run with run_ref: "…"`, copy that handle into **`run_ref`** on the next **`plasm_run`** (same **`logical_session_ref`**; no second **`plasm`** call). Use paging only when **no** run snapshot was stored for that step. When a snapshot URI is present, read it first — the snapshot holds the complete materialized batch; paging is not a substitute for artifact read. `page(...)` is HTTP-execute program syntax only — not an MCP tool argument.

**Live execute:** server spawns one async operation and awaits terminal rows in the tool response. Progress uses standard `notifications/plasm/op` on the registered handle.

**Live results:** `## {return_label} ({n} rows)` header always. **Small results (≤25 rows):** inline ` ```tsv ` in tool **`content`** — use directly; live runs may still store a server-side snapshot for Run Explorer. Check **`structuredContent.plasm.result_delivery`**: `inline` means rows are in **`content`**; `snapshot_only` means fetch via the artifact read path (suffix below). A `plasm://…` snapshot line or `(in artifact)` cells in **`content`** also require artifact read. Multi-return programs use `# Results` with `### {label} ({n} rows)` per root. **`structuredContent.plasm.index_delta`** is not the row payload channel.

**Retry:** transient `session materialization changed during concurrent execute` — re-issue the same `plasm_run` once.
