**Run Plasm** executes real API operations: pass `logical_session_ref` and the exact `run_ref` from a reviewed plan or a returned page handle. Send Python source to `plasm`.

Clean read-only `plasm` calls already execute. Never guess a reference or execute those reads again.

Each reviewed commit authorizes one execution. A deliberate repeat requires a fresh plan review and new run_ref. If a reference is missing, expired or mismatched, resubmit the program to `plasm` in the same session with the same selection criteria.

A preview may omit rows or fields; it does not establish absence or collection completeness. Inspect coverage and follow a returned continuation with the same logical_session_ref.

A failed or cancelled run may have completed writes. Inspect operation outcomes and reconcile uncertainty before further effects; do not blindly replay a program. A rejected duplicate dispatches nothing and does not undo the earlier execution.

Failure evidence belongs to one execution. A new program does not resume or roll back an earlier execution; service diagnostics do not determine effect status.
