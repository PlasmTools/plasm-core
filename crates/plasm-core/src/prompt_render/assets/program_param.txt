Plasm source text, not JSON data — one expression, or `label = …` bindings then ONE final return line (comma-separated roots on that line only). No prose, no `return` keyword, no code fences. Echoing a bare object/array/string literal is a no-op; write Plasm source.

Symbols from the `plasm_context` teaching TSV: `e#` entity, `m#` method, `r#` relation; **wire names** for fields, params, and filters. Substitute real values for teaching placeholders (`$`, `<id>`); never emit `$`.

Shape:
- Get by identity: `e#(id)` (parens). Query/filter: `e#{field="val"}` (braces). Relation nav: `producer.r#`.
- Search when taught: `e#~"text"` or `e#~$` (bare `e#~` is a parse error).
- Postfix from the TSV left column: `.filter{…}` `.sort(field,desc)` `.limit(n)` `.group_by` `.aggregate` `.with{k: expr}`; `[field,…]` projects.
- Write: `source => e#.m#(param=…)`; create: `e#.m#(param=…)`. Prior write **`provides`** fields usable as later args; `[field,…]` on creates projects them.
- After `repo = e#(…)`, prefer **`repo.m#(…)`** / **`repo.r#`**.
- Multi-write / batch-read shape: see the `plasm` tool description.

Strings use JSON escapes inside quotes; multiline: `label = <<TAG` … `TAG` (pass `param=label`). Row-to-text: `label = source[field,…] <<TAG` — use `binding.content` for string params.

Full grammar is in the `plasm` tool description. Session / parse recovery: see **`plasm_context`** (`session_mode: "extend"`, same `logical_session_ref` — not `new`).
