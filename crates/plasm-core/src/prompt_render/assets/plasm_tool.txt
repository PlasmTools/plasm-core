**Plasm** — **`logical_session_ref`** + **`program`**. Clean read-only plans execute inline (rows in tool **`content`**). Plans with any mutation / review gate return a **`run_ref`** (`pcN`, 10 min TTL) for **`plasm_run`**; do **not** echo the program.

**`program` is Plasm source text, not JSON data.** Grammar below; symbols from the language card. Reply with one valid plasm_program:

**Program shape:** one `plasm_expr`, or `label = …` bindings then **one** final return line (comma-separated roots on that line only). No prose, `return`, fences, or table rows.

**Strings:** JSON escapes in quotes (`\n` `\t` `\\` `\"`); prefer tagged `<<TAG` … `TAG` heredocs for long bodies (real newlines).

**Batch independent reads** (required): shared scope + multi-root return — not N tool cycles.
```
foo = e1(id="a")
bars = e2{foo=foo}
bazs = e3{foo=foo}
bars, bazs
```
Batch reads aggressively. After a write use **`label.wire`** from that binding — never invent a `.wire` not taught on the card.

**Language-card Meaning:**
- Header `plasm_expr<TAB>Meaning`; **left column only is syntax** — never copy Meaning.
- Executable rows start with `e#`; `r#`/`v#` are never roots. Wires appear on field-gloss / bracket rows by first use.
- Never emit `v#`. Fill every card hole with a real value.

**Membership plane (prefer `| where`):** Materialize with `e#` / `e#{wire=tok}` then filter membership with `| where wire = tok`. Use entity-head `e#{wire=tok}` for catalog / backend selection. Bare taught tokens either way — never copy `<…>`, never leave `|` alternatives. Never emit `v#`.

**Date/time:** `| where ts >= "…"` with `"Nd ago"` / `"today"`·`"yesterday"`·`"last week"`·`"this year"` / `"last monday"` / RFC3339 (quote multi-word) — not brace `min_*`, not `now()`/`date_*`.

**Three strata** (catalog · `|` row algebra · `=>` application):

1. **Catalog source** — `e#` / `e#{wire=value}` / `e#~"q"` / `e#(<id>)` — before `|` stages or bare (no `|`). Backend WHERE only on an **entity head**.
2. **Row algebra** — `|` stages left-to-right (never after `=>`): `| where …` · `| select fields, name = expr` · `| summarize [by keys] n=count()` · `| order by f [desc]` · `| take n` · `| distinct [by f]`. Bind cuts: `rows = e# | where …` then `rows | select …` or `rows => …`.
3. **Application `=>`** — when per-row args vary: `{ t: _.f }` · `<<TAG` Jinja · `e#.m#(…, _.f)` · `_.r#` / `_.wire`. Always `_` for row variance. Dots `.m#` / `.r#` only on a proven Get singleton: `item = e#("id"); item.update(…)`.

**Catalog vs row plane:** backend WHERE is `e#{wire=value}` on an entity head; row filter is `e# | where …` or `rows = e#` then `rows | where …`. Invalid: `rows{wire=…}` on a binding.

**Forbidden as row algebra:** `.filter` / `.with` / `[proj]` / `.group_by` / `.sort` / `.limit`, `| update`, `| take 1` then `.update` for multi-row, bare `=> tags` without `_`.

**Composition:**
- Row text: `label = source => <<TAG` … `TAG` — never root `e#[…]<<` or bare `source <<TAG`. String params take **`binding.content`**. Interpolation: `${report.content}` (`$$` escapes `$`).
- Plural write: `rows => e#.m#(…, _.f)`. Bare create: `e#.m#(param=…)`.
- Quote scalars in `{…}` and string params.

**Recovery:** `dry_verdict: needs_fix` → revise `program`, call **`plasm`** again on the same **`logical_session_ref`**. **`plasm_context`** `session_mode: "extend"` when symbols are missing — never **`new`**.
