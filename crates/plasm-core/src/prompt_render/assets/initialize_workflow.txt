Plasm MCP tools (in order): **`plasm_context`** (session + teaching TSV) → **`plasm`** (dry-run plan) → **`plasm_run`** (live execute); **`discover_capabilities`** first only when `api`/`entity` is unknown.
**One workflow → one `logical_session_ref`.** Call **`plasm_context`** with **`session_mode: "new"`** once, then **`session_mode: "extend"`** + the same ref for later turns. **`intent`** accumulates each turn — it does **not** select the session.
**`plasm_context`** returns the teaching TSV; use its `e#`/`m#`/`p#`/`r#` only. Reuse ref for `plasm` / `plasm_run`; extend with more `seeds` / corrected `ranked_capabilities` — never `session_mode: "new"` to recover from parse errors.
**`plasm`** is plan-only — pass its returned **`run_ref`** (`pcN`) to **`plasm_run`**; don't re-send the program. **Live rows:** ≤25-row **`plasm_run`** results inline TSV in tool **`content`** (`result_delivery`: `inline`); larger or reference-only results need **`resources/read`** or **`plasm_read_run_artifact`**. **Paging:** copy `next_run_ref` into **`run_ref`** on **`plasm_run`** only when no snapshot was stored for that step (not `page(...)` — HTTP-execute program syntax).
