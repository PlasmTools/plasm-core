Plasm MCP: **`plasm_context`** is the default first call — **`session_mode: "new"`** + **`intent`** only on semantic-auto-seed hosts (opens teaching TSV + mints **`logical_session_ref`**). Then **`plasm`** (dry-run plan) → **`plasm_run`** (live execute).
**Do NOT** start workflows with a separate browse step on semantic-auto-seed hosts — **`hard_miss`**/**`clarify`** breakout text includes capped catalog browse rows; retry with explicit **`seeds`**.
**One workflow → one `logical_session_ref`.** Call **`plasm_context`** with **`session_mode: "new"`** once, then **`session_mode: "extend"`** + the same ref for later turns. **`intent`** accumulates each turn — it does **not** select the session.
**`plasm_context`** returns the teaching TSV; use its `e#`/`m#`/`r#` and wire names for fields/params/filters. Reuse ref for `plasm` / `plasm_run`; extend with more `seeds` / corrected `ranked_capabilities` — never `session_mode: "new"` to recover from parse errors.
**`plasm`** is plan-only — pass its returned **`run_ref`** (`pcN`) to **`plasm_run`**; don't re-send the program. **Live rows:** ≤25-row **`plasm_run`** results inline TSV in tool **`content`** (`result_delivery`: `inline`); larger or reference-only results need **`resources/read`** or **`plasm_read_run_artifact`**. **Paging:** copy `next_run_ref` into **`run_ref`** on **`plasm_run`** only when no snapshot was stored for that step (not `page(...)` — HTTP-execute program syntax).
