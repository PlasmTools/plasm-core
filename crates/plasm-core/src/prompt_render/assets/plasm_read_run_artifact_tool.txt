Requires `logical_session_ref` plus exactly one of `run_id` or `artifact_uri` copied from the same `_meta.plasm.steps[]` entry — not `run_step`, not `resource_index`, not `meta_generation` / `dict_ref`. Returns the same bytes as MCP `resources/read`.
