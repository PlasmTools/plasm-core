**JSON `program` string:** Use literal newline characters (U+000A) between statements when you have more than one binding—typically one `ident = …` per line, then bare comma-separated roots on the last line(s). Spaces do not separate statements. (Wire JSON may show `\n`; the parsed string must still contain real newlines.)

**Heredoc:** After `<<TAG` on the opener line, start the body on the next line; close with a line whose trimmed text is `TAG` (or `TAG)` / `TAG,` / `TAG}`). First trimmed-line match closes the heredoc—use a long opaque `TAG` not present in the body.

Executable grammar (`e#` / `m#` / `p#`), bracket-render, `.content`, and postfix pitfalls (substitute teaching `$`/`~"text"` fill-ins): **`plasm_context` teaching TSV** preamble on first wave—not repeated in tool descriptions.
