**JSON `program` string:** Prefer `\n` between bindings, then bare comma-separated roots. Single-line space-separated bindings are **supported** (not preferred); coercion rewrites a **trailing** root to the **first** binding when it differs (`metadata.coerced_default_return` may be set). Decoded strings need real newlines for heredocs.

**Heredoc:** After `<<TAG`, body on next line; close with trimmed `TAG` (or `TAG)` / `TAG,` / `TAG}`). Use a long opaque `TAG` not in the body.

Symbols: `e#` entity, `m#` method, `p#` field/filter/param, **`r#` relation nav**, `v#` value-domain. Relation fanout: copy `.r#` or wire from exemplars — not bare `p#` after `.` on a receiver. Homograph: `labels = issues.p#` forgiven only when binding name matches relation wire; prefer exemplar `.r#`/wire. Grammar: **`plasm_context` teaching TSV** preamble.
