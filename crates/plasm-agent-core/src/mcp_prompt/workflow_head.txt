Plasm MCP tools (in order): **`plasm_context`** (session + teaching TSV), **`plasm`** (dry-run plan), **`plasm_run`** (live execute), **`discover_capabilities`** (when **`api`/`entity`** unknown). Skip discover when seeds are known.
     **One goal → one stable **`intent`** → one **`plasm_context`**.** `logical_session_ref` (`s0`, …) is per goal, not per API. Multi-API: one **`seeds`** array (example in **`plasm_context`** tool).
     **`discover_capabilities`**: one **`intent`** per goal (whole task in one sentence). Reply table → merge into **`plasm_context`** **`seeds`**. Retry if entities missing; **`typed: true`** when ambiguous.
     **`plasm_context`**: **`intent`** + **`seeds`**; returns **`logical_session_ref`** + teaching TSV. **Steady state:** reuse ref with **`plasm`** / **`plasm_run`**; do not repeat identical **`seeds`**.
