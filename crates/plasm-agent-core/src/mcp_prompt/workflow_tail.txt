     **`plasm`** is **plan-only** (no live HTTP). Prefer **one** `program` per call (comma-separated roots on the final line for multi-return). Multi-root answers: review with **`plasm`**, execute with **`plasm_run`**. Never prefix roots with `return`.
     **`plasm_run`**: same args as **`plasm`**; live HTTP after plan review. May return run snapshot URIs.
     **Paging:** **`page(s0_pgN)`** / `_meta.plasm.paging` in the same logical session.
     **Long ops:** **`wait(s0_oN)`** poll · **`cancel(s0_oN)`** cancel · compact op lines: **`+`** accept · **`~`** running · **`=`** unchanged · **`!`** done · poll slowly (3–5s).
     **Snapshots:** `plasm://…` → **`resources/read`** when Markdown points there.
