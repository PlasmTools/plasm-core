**Run Plasm** (live): same **`logical_session_ref`** + **`program`** (+ optional **`reasoning`**) as **`plasm`**. Real HTTP/API; may return **`resource_link`** / `_meta.plasm` snapshots.

**Review gate:** when dry-run verdict is `review`, pass matching **`plan_commit_ref`** (`pcN` from prior **`plasm`**) or **`force: true`**.

**Async accept:** compact **`+`** wire line + handle — not final rows; **`plasm_run program=wait(l_<token>_oN)`** until **`!`**, **`x`**, or **`?`** before unrelated live programs or telling the user the run finished. **`~`** = progress changed; **`=`** = still open but unchanged — keep polling.

**Live results:** `## {return_label} ({n} rows)` + TSV/table; multi-return programs use `# Results` with `### {label} ({n} rows)` per root. Truncated rows: `_meta.plasm.steps` + MCP **`resources/read`** on snapshot URIs — required before concluding fields are absent.
